# Reverse a linked list

Read `n` and `n` integers, and build a singly linked list in that order. **Reverse it by changing the
`next` pointers** (no new nodes, no vector), then print the values.

**Input** `4` / `1 2 3 4`, **Output** `4 3 2 1`

Visualize your solution: you should see the arrows flip one by one.
