# All subsets

Read `n` (0 ≤ n ≤ 10) and `n` distinct integers given in increasing order. Print every subset, one per line, as `{a b c}` (empty set: `{}`), in lexicographic order of the sequences, which is the order a depth-first search produces:
`{}`, `{1}`, `{1 2}`, `{1 2 3}`, `{1 3}`, `{2}`, ...
