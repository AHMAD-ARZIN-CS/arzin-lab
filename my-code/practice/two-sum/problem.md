# Two Sum (LeetCode #1 style)

Read `n`, then `n` integers, then a `target`. Print the indices `i j` (0-based, `i < j`) of the two
numbers that add up to `target`. Exactly one answer exists.

**Input**
```
4
2 7 11 15
9
```
**Output** `0 1`

Start with the simple O(n^2) version. Then ask for **Optimize** and compare both versions on the tests.
